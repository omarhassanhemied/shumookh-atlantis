# لاندينج بيدج شموخ أطلنتس — خدمات العزل

صفحة ثابتة (HTML + CSS + JavaScript عادي بدون فريمورك)، عربي RTL افتراضي مع إنجليزي، جاهزة للإعلانات من الموبايل.

## الملفات

```
index.html            الصفحة الرئيسية
leak-detection.html, waterproofing.html, thermal-insulation.html,
roof-insulation.html, building-insulation.html     صفحات الخدمات (5)
blog.html + article-*.html                         صفحة المقالات و6 مقالات
robots.txt            (و sitemap.xml بيتولد لما تكتب الدومين وتشغّل البناء)
css/style.css         التصميم والألوان (متغيرات :root فوق)
js/config.js          بيانات الشركة والأرقام والتتبع  ← هتعدل هنا
js/translations.js    كل النصوص (عربي + إنجليزي)      ← وهنا
js/pages.js           محتوى صفحات الخدمات والمقالات (عربي + إنجليزي) ← وهنا
js/main.js            السلوك (لا تحتاج تعدله)
assets/logo/          نسخ اللوجو المقصوصة (من اللوجو الأصلي بدون تعديل)
assets/hero|services|projects/   الصور (حالياً مؤقتة وموسومة "توضيحي")
assets/backgrounds/   نقش الأقواس (SVG)
IMAGE_PROMPTS.md      برومتات الصور بالأسماء والمقاسات
tools/                (اختياري) index.template.html + build.js (بيبني كل الصفحات)
```

## قبل النشر — لازم تراجع

- [ ] **الإيميل**: مخفي. اكتبه زي اللوجو في `config.js` (`email.value`) وغيّر `confirmed` إلى `true`.
- [ ] **الاسم الإنجليزي** `Shumookh Atlantis`: كتابة صوتية من اللوجو (اللوجو عربي فقط). عدّله أو أكّده.
- [ ] **رقم الهاتف**: الموجود `+966 58 323 2039` (مأخوذ من شاشة واتساب اللي بعتها). أكّده، ولو فيه رقم تاني حطه في `phones`.
- [ ] **المدن**: `cities` فاضية. لو حطيتها بتظهر في شريط الثقة والاقتراحات في الفورم ومعلومات SEO.
- [ ] **العنوان والخريطة**: غير موجودين (ما اتخترعش عنوان). لو أكدت العنوان حطه في `address`.
- [ ] **نصوص الخدمات وقسم "لماذا نحن" والأسئلة الشائعة**: كتبتها بصياغة عامة غير رقمية. راجعها وعدّلها لتعكس شغل الشركة فعلاً.
- [ ] **آراء العملاء**: أماكن فاضية عمداً. لما يتوفر رأي حقيقي بموافقة العميل ضيفه، أو اخفي القسم: `sections.testimonials: false`.
- [ ] **الدومين**: لما يتحدد ضعه في `domain`، وبعدها في `index.html` غيّر `og:image` لرابط كامل (مثال: `https://example.com/assets/logo/og-image.jpg`) وأضف `<link rel="canonical" href="...">`.
- [ ] **التتبع**: ضع المعرفات في `tracking` (GTM / GA4 / Meta Pixel / TikTok Pixel). الفاضي = مفيش أي كود بيتحمّل. الأحداث (اتصال / واتساب / فورم) بتتبعت تلقائياً لما يتفعّل التتبع.
- [ ] **الصور**: بدّل الصور المؤقتة (`IMAGE_PROMPTS.md`). الصور المولّدة أو المجانية تفضل موسومة "توضيحي" ولا تتقدم كمشاريع الشركة. عند استخدام صور مشاريع حقيقية فقط: `illustrativeImages: false`.
- [ ] **سوشيال**: ضع الروابط في `social` (فاضي = مش بيظهر).
- [ ] **كشف التسربات**: اسم الحساب في واتساب فيه "كشف تسربات"، لكن اللوجو فيه 4 خدمات فقط (مائي / حراري / أسطح / مباني) فالصفحة مبنية عليهم. لو الخدمة موجودة فعلاً قول لي أضيفها.

## تغيير البيانات والنصوص

- **أرقام / مدن / عنوان / سوشيال / تتبع**: `js/config.js` (الأرقام بأي صيغة `05...` أو `+966...` وتتحول تلقائياً).
- **أي نص**: `js/translations.js` (قسم `ar` وقسم `en`).
- رسالة واتساب بتكون **بالعربي دايماً** (مكتوبة في `translations.js` تحت `wa.*`).
- النماذج مفيهاش سيرفر: الزر يفتح واتساب برسالة جاهزة، ومفيش رسالة نجاح وهمية.
- **ملحوظة SEO**: النص العربي موجود داخل `index.html` نفسه (للمحركات)، والنصوص الفعلية بتتحمّل من `translations.js`. بعد تعديل كبير في النصوص العربية شغّل (على كمبيوتر فيه Node): `node tools/build.js` لتحديث النص داخل كل الصفحات. لو ما شغلتهوش الصفحات تشتغل عادي (النص بيتحمّل من الجافاسكربت).

## تغيير الصور

استبدل الملف بنفس الاسم والمجلد (WebP): `assets/hero/hero-main.webp`، `assets/services/*.webp`، `assets/projects/*.webp`. المقاسات والبرومتات في `IMAGE_PROMPTS.md`.

## الألوان والخطوط

- ألوان الهوية مستخرجة من اللوجو: كحلي `#0C2635`، برونز `#B48958`، كريمي `#F6E5DD` (في `:root` داخل `style.css`).
- الخطوط المقصودة: **IBM Plex Sans Arabic** (للنص) و **Reem Kufi** (للعناوين). مش متضمنة في الملفات (ممنوع روابط خارجية). لتفعيلها: حمّل ملفات WOFF2 (ترخيص OFL) وحطها في `assets/fonts/` ثم فعّل أسطر `@font-face` الموجودة (معلّقة) أعلى `style.css`. بدونها بيستخدم الصفحة خطوط الجهاز وتعمل بشكل سليم.

## الرفع

**GitHub Pages**: ارفع محتويات المجلد (index.html في الجذر) إلى مستودع جديد ← Settings ← Pages ← Deploy from a branch ← main / root.

**Vercel**: New Project ← اربط المستودع (أو اسحب المجلد) ← Framework: Other ← Deploy. بدون Build Command.

**Netlify**: Add new site ← Deploy manually ← اسحب المجلد (أو ملف ZIP الجاهز اللي index.html في جذره).

من الموبايل: ملف ZIP الثاني (`...-mobile.zip`) جاهز للرفع المباشر لأن `index.html` في جذره.

## الصفحات والمقالات (جديد)

- **خدمة كشف التسربات**: خدمة رقم 5 في الصفحة الرئيسية (كارت عريض) ولها صفحة خاصة `leak-detection.html`، وبتظهر في الفورم والفوتر ورسالة واتساب تلقائياً.
- **كل نص الخدمات والمقالات** في `js/pages.js` (عربي وإنجليزي جنب بعض). عدّل النص هناك، وبعدها شغّل `node tools/build.js` لو عايز النص العربي يتحدّث داخل ملفات الـHTML للمحركات.
- **مقال جديد**: انسخ عنصر من مصفوفة `ARTICLES` في `pages.js` وغيّر `id` و`file` والنص، ثم `node tools/build.js` (بيعمل ملف الصفحة). الصور من `assets/`.
- المقالات **عامة وتعليمية** ومفيهاش ادعاءات عن الشركة (سنوات/أجهزة/شهادات/أرقام). **راجعها وصفحات الخدمات مع العميل** قبل النشر، خصوصاً صفحة كشف التسربات وما ذُكر فيها عن خطوات العمل.
- صورة `assets/services/leak-detection.webp` مؤقتة (من صور الحمام) وموسومة "توضيحي" — استبدلها بالبرومت في `IMAGE_PROMPTS.md`.
- **SEO**: اكتب `domain` في `config.js` ثم شغّل `node tools/build.js` ليتولد `sitemap.xml` و`robots.txt` بالدومين.
- تقدر تبعت أي صفحة بلغة معينة بإضافة `?lang=en` للرابط، واللغة المختارة بتفضل معاك في باقي الصفحات.
